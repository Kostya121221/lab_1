# Лабораторная работа № 1: абстрактные структуры данных

Реализация на Go. Программа содержит динамический массив, односвязный и двусвязный списки, стек, очередь и AVL-дерево. Данные сохраняются стандартным пакетом `encoding/json`. Исходный код не содержит комментариев.

## Сборка и запуск

```bash
go build -o dbms .
./dbms --file file.json
```

Либо:

```bash
make
./dbms --file file.json
```

Для одной команды без интерактивного режима:

```bash
./dbms --file file.json --query 'CREATE M numbers'
./dbms --file file.json --query 'MPUSH numbers 10'
./dbms --file file.json --query 'MREAD numbers'
```

## Организация кода

`main.go` читает команды. Общие команды обрабатываются в `execute()`, после чего `switch` направляет операции в один из шести обработчиков: массив, односвязный список, двусвязный список, стек, очередь или AVL-дерево. В каждом обработчике отдельные ветви `switch` соответствуют командам этого контейнера.

Структуры и операции разделены по файлам: `array.go`, `singly_list.go`, `doubly_list.go`, `stack.go`, `queue.go` и `avl_tree.go`. Общие функции управления контейнерами находятся в `database.go`. Односвязный список хранит только голову; двусвязный список хранит голову, хвост и размер. AVL-дерево автоматически выполняет повороты после вставки и удаления.

`storage.go` сохраняет и загружает JSON стандартным пакетом Go. Сторонние зависимости не нужны.

## Формат JSON

Имя контейнера является ключом верхнего уровня. Для контейнера сохраняются поля `type` и `data`.

```json
{
  "numbers": {
    "type": "array",
    "data": ["10", "20"]
  },
  "myStack": {
    "type": "stack",
    "data": ["second", "first"]
  },
  "myTree": {
    "type": "tree",
    "data": ["10", "20", "30"]
  }
}
```

Имена контейнеров должны быть уникальными между всеми типами. После успешного изменения данные автоматически сохраняются в файл. Команды добавления выводят добавленное значение в формате `-> значение`, а не `OK`. Значения AVL-дерева сравниваются как строки.

## Команды

- `CREATE <M|F|L|S|Q|T> <имя>` — создать контейнер.
- `DROP <тип> <имя>` — удалить контейнер.
- `PRINT <тип> <имя>` — вывести содержимое.
- `SAVE`, `LOAD`, `HELP`, `EXIT` — сохранить, загрузить, показать справку, завершить работу.
- `M`: `MPUSH`, `MINSERT`, `MGET`, `MSET`, `MDEL`, `MLEN`, `MREAD`.
- `F`: `FPUSH`, `FPUSHFRONT`, `FINSERTBEFORE`, `FINSERTAFTER`, `FDEL`, `FDELHEAD`, `FDELTAIL`, `FDELBEFORE`, `FDELAFTER`, `FGET`, `FREAD`, `FSEARCH`.
- `L`: `LPUSH`, `LPUSHFRONT`, `LINSERTBEFORE`, `LINSERTAFTER`, `LDEL`, `LDELHEAD`, `LDELTAIL`, `LDELBEFORE`, `LDELAFTER`, `LGET`, `LREAD`, `LSEARCH`.
- `S`: `SPUSH`, `SPOP`, `SGET`, `SREAD`.
- `Q`: `QPUSH`, `QPOP`, `QGET`, `QREAD`.
- `T`: `TINSERT`, `TSEARCH`, `ISMEMBER`, `TDEL`, `TGET`, `TREAD`.

Индексы массива и списков начинаются с нуля. `FREAD` и `LREAD` принимают необязательный аргумент `REVERSE`.
